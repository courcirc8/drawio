# power-v1 — tuning set for power topologies (2026-10-03)

Nine textbook power circuits written by hand for this set (names and values
differ from the LTspice holdout): Graetz bridges, half-wave rectifier,
Greinacher doubler, two-stage Cockcroft-Walton, H-bridge and half-bridge
with freewheel diodes, three-phase six-diode bridge, buck converter.

Why: the holdout-ltspice errors were 45 % power electronics, and no tuning
set contained any — rules for them could only have been tuned on the
holdout, which the holdout contract forbids. Rules are tuned HERE, then
measured on holdout-ltspice.
