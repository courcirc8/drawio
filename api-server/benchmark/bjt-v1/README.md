# bjt-v1 — tuning set for discrete BJT circuits (2026-10-03)

Nine textbook BJT circuits written by hand for this set (mirrors: simple,
Widlar, Wilson; differential pair; CE stage; CE + emitter follower; zener
shunt and series-pass regulators; class-AB push-pull). The
tuning sets were MOS-only for mirrors, and BJT mirror defects showed only
on the holdout, where rules must not be tuned. Tune here, measure there.
